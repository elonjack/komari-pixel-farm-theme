# 田野监控站（Pixel Farm）

一个原创像素农场风格的 Komari **只读**监控主题。每个 Komari 节点是一块田地；主题根据节点最新状态显示茁壮、缺水、警讯或休耕视觉状态。主地图是主题内置的原创瓦片渲染，不使用《星露谷物语》的角色、UI 或游戏素材。

## 安装

1. 将本目录压缩为 `pixel-farm.zip`。压缩包根目录必须直接包含 `komari-theme.json` 与 `dist/`。
2. 在 Komari 后台的主题管理中上传 ZIP 并启用。
3. 在“田野监控站设置”中设定农场名称与刷新间隔。

不要把整个仓库目录作为一层再压缩；否则 Komari 找不到根目录的 manifest。

在 GitHub Releases 下载主题时，选择 `pixel-farm-theme-v*.zip` 这个发布附件后直接上传；不要下载 GitHub 自动生成的 `Source code (zip)`，它不是 Komari 可安装包。

## 状态规则

- 茁壮：最近 2 分半钟内有状态，CPU、内存、磁盘均低于 70%。
- 缺水：其中至少一项为 70%–89.99%。
- 警讯：其中至少一项达到 90%。
- 休耕：无有效最近状态或状态超过 2 分半钟。这**不等于**节点离线，可能只是 Agent 未上报或请求暂时失败。

主题会额外读取每台节点最近 1 小时的 Komari Ping 记录：田牌显示默认检测点的平均延迟与丢包率，详情页列出每个检测点的平均/最低/最高延迟和丢包。Ping 丢包大于 0% 或平均延迟达到 200 ms 会标为“留意”；丢包达到 10% 或平均延迟达到 500 ms 会标为“警讯”。未配置 Ping 任务时会显示“未配置”。

节点国家来自 Komari 节点的 `region` 字段：两位国家代码（如 `US`）与国旗（如 `🇺🇸`）会显示中文国家名称；自由文本地区则原样显示。

网络上下行只用于信息展示，不参与健康评级；这样高流量业务不会被错误标成异常。

## 安全与边界

- 只请求同源的 `GET /api/public`、`GET /api/nodes` 和 `GET /api/recent/{uuid}`；没有写入 API、令牌、外部资源或第三方脚本。
- 所有来自 API 的文本均使用 `textContent` 写入 DOM，不使用 `innerHTML`，避免节点名称、分组等字段造成脚本注入。
- UUID 会在请求前校验并 URL 编码；状态请求设置 10 秒超时且最多并发 6 个，避免节点很多时集中打满浏览器连接。
- `theme_settings` 是公开数据，主题也明确提示管理员不要在主题配置中填写秘密。此版本不储存积分、用户身份或种植数据。

## 后续版本

种子、收获、积分和等级需要经认证的服务端数据存储；不能放在公开的主题配置中。第二阶段若只做“单浏览器游玩”，可以使用本地存储；真正多用户玩法应通过经权限校验的 Komari 插件或独立服务实现。
